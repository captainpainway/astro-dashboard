# Sky Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sixth page, **sky**, that shows the home tile's sky full-size with every target in tonight's plan,
filters, layers, time controls and search, sharing its time, direction and zoom with the tile.

**Architecture:** The tile's canvas, overlay and gestures move into `SkyStage.vue`; the time, view and intro move into
an App-owned `useSkyView()` composable. `SkyPanorama` (tile) and the new `SkyPage` each wrap one `SkyStage` and call
`sky.follow(...)`. New pure helpers (target lists, line layers, search, time steps) live in `src/engine/sky.js`.

**Tech Stack:** Vue 3 (`<script setup>`), `astronomy-engine`, GSAP 3 (`Draggable`, `InertiaPlugin`, already
installed), raw WebGL1, vitest + jsdom + `@vue/test-utils`, Playwright / chrome-devtools MCP for browser checks.

**Spec:** `docs/superpowers/specs/2026-10-05-sky-page-design.md`

**Working rules:** work directly on branch `next_level`. Never leave build output in the repo: build only with
`--outDir` in the scratchpad, and save screenshots to the scratchpad. No new dependencies. Commit messages are plain
sentences, like the existing history. Comments follow the repo's style (no branch tags, at most 3 lines).

## Spec deviations (decided while planning)

1. **`useSkyView()` takes no argument.** The component that shows the sky calls `sky.follow(() => props.location,
   { targets, bestHour })`; `follow` attaches the location (a new one re-opens the sky, the same one keeps everything)
   and re-faces the #1 target when the target ids change. That already gives "intro once per location", so there is
   no `introPlayed` flag.
2. **Existing tile tests keep every assertion.** Their mounts gain `sky: useSkyView()`, because the tile now needs the
   shared state as a prop.
3. **The expand icon sits at the end of the tile's scrubber row**, where the credits link was.
4. **The sky page's stage is `immersive`:** a plain scroll wheel zooms (no Ctrl needed) and one finger drags in both
   directions on touch screens. The page fills the viewport, so there is no page to scroll inside the sky.
5. **One "Targets (n)" toggle in the toolbar on every width:** it collapses the column on desktop and opens the sheet on
   phones; the list's ✕ closes it too.
6. **`bestDarkHour(hours)` moves to `src/engine/forecast.js`** (second caller: `App.vue` needs it for the page).
7. **The time label lives in `useSkyView` (`sky.timeLabel`)** and the scrubber track becomes `SkyScrubber.vue`, shared by
   the tile and the page.
8. **Hovering a row shows that ring's tooltip** (the stage's `hoverId` prop) rather than a separate highlight style.
9. **The below-horizon search notice is a page-level toast** (`.sky-notice`, also the live region), not the stage hint.
10. The sky page's header is the home header (location + "change" + picker).

## Global Constraints

- No new dependencies; raw WebGL1; no continuous animation loop while idle; device pixel ratio capped at 2.
- `sky.json` stays under 30 KB gzip; its new `starNames` come from d3-celestial (© 2015 Olaf Frohn, BSD-3-Clause).
- Rings stay 24px (touch-target audit); rings outside the top 10 by score are drawn at 45% opacity until hovered or
  selected.
- `prefers-reduced-motion`: no intro, instant turns and zooms, no tooltip spring; play jumps an hour per second.
- All times shown in the **site's** time zone (`sky.timeLabel`, `fmtTime`).
- Layers persist in `localStorage` key `astrodash.skyLayers`, every access wrapped in try/catch.
- Tests are network-free; run with `npx vitest run <files>`; `tests/SkyPage.test.js` is the only new test file.

```js
import { computed, reactive, ref, shallowRef, watch } from 'vue'
import { gsap } from 'gsap'
import { altAzOf, introEnd, nightRange, skyAt, targetHorizon, turnTarget } from '../engine/sky'
import { toLocalIso } from '../engine/time'
import { fmtTime } from '../format'
import { reduceMotion } from '../motion'

export const ZOOM_STEP = 1.5

/**
 * What the sky shows, shared by the home tile and the sky page: the time, view direction and zoom, and the intro.
 * App.vue owns one. The component showing the sky calls `follow`: a new location re-opens the sky, while switching
 * pages keeps everything as it was.
 */
export function useSkyView() {
  const location = shallowRef(null)
  const view = reactive({ yaw: 180, pitch: 25, zoom: 1 })
  const now = ref(new Date())
  const time = ref(now.value.getTime())
  const zoomMax = ref(4) // set by the mounted SkyStage from its width
  const range = computed(() => (location.value ? nightRange(location.value, now.value) : null))
  const frame = computed(() => (location.value ? skyAt(location.value, new Date(time.value)) : null))
  const timeLabel = computed(() =>
    (location.value ? fmtTime(toLocalIso(new Date(time.value), location.value.timezone)) : ''))
  let plan = { targets: () => [], bestHour: () => null }
  let intro = null
  let touched = false // after any drag, key, scrub or turn the camera is the visitor's until the next location

  function stopMotion() {
    intro?.kill()
    intro = null
    gsap.killTweensOf(view)
  }
  function touch() {
    touched = true
    stopMotion()
  }

  /** The highest-scoring target above the horizon at `date`, as alt/az; south at 25° when none is up. */
  function topAt(date) {
    const f = skyAt(location.value, date)
    const up = plan.targets().map((t) => ({ t, v: targetHorizon(t, f) })).filter(({ v }) => v && v[2] > 0)
    const best = up.sort((a, b) => b.t.score - a.t.score)[0]
    return best ? altAzOf(best.v) : { alt: 25, az: 180 }
  }
  function face(date, animate) {
    const goal = turnTarget(view, topAt(date), 20)
    if (animate && !reduceMotion()) gsap.to(view, { ...goal, duration: 1, ease: 'power2.inOut', overwrite: true })
    else Object.assign(view, goal)
  }

  /** At night: now, facing the #1 target. In daytime: the intro from sunset to the best moment (or its end state). */
  function open() {
    stopMotion()
    touched = false
    view.zoom = 1
    now.value = new Date()
    const { start, end } = range.value
    const t = now.value.getTime()
    if (t >= start && t <= end) {
      time.value = t
      return face(now.value, false)
    }
    const stop = () => introEnd(range.value, plan.bestHour()).getTime()
    if (reduceMotion()) {
      time.value = stop()
      return face(new Date(time.value), false)
    }
    time.value = start.getTime()
    const from = { yaw: frame.value.sun.az, pitch: 25 } // facing the sunset glow
    Object.assign(view, from)
    const p = { v: 0 }
    intro = gsap.to(p, {
      v: 1, duration: 4, ease: 'power2.inOut',
      onUpdate() {
        // Read every frame, so a forecast or plan arriving mid-intro retargets it smoothly.
        const e = stop()
        const goal = turnTarget(from, topAt(new Date(e)), 20)
        time.value = start.getTime() + p.v * (e - start.getTime())
        view.yaw = from.yaw + p.v * (goal.yaw - from.yaw)
        view.pitch = from.pitch + p.v * (goal.pitch - from.pitch)
      },
      onComplete: () => { intro = null },
    })
  }

  function attach(loc, how) {
    plan = how
    if (loc === location.value) return
    location.value = loc
    open()
  }
  function retarget() {
    if (!touched && !intro) face(new Date(time.value), true)
  }
  /** Call once from the setup of the component showing the sky; its watchers stop when it unmounts. */
  function follow(getLocation, how) {
    attach(getLocation(), how)
    watch(getLocation, (loc) => attach(loc, how))
    watch(() => how.targets().map((t) => t.id).join(), retarget)
  }

  function setTime(t) {
    touch()
    time.value = t
  }
  /** Turn to `altAz` the short way; below the horizon, face its direction with the camera as low as it goes. */
  function turnTo(altAz) {
    touch()
    const goal = turnTarget(view, altAz)
    if (altAz.alt <= 0) goal.pitch = 5
    if (reduceMotion()) Object.assign(view, goal)
    else gsap.to(view, { ...goal, duration: 0.8, ease: 'power2.inOut' })
  }
  const clampZoom = (z) => Math.min(zoomMax.value, Math.max(1, z))
  function zoomBy(factor, animate = true) {
    touch()
    const zoom = clampZoom(view.zoom * factor)
    if (animate && !reduceMotion()) gsap.to(view, { zoom, duration: 0.3, ease: 'power2.out' })
    else view.zoom = zoom
  }

  return reactive({
    location, view, now, time, zoomMax, range, frame, timeLabel, follow, touch, setTime, turnTo, zoomBy, clampZoom,
  })
}
```

```vue
<script>
// Ring colours and labels per instrument; the sky page's target list uses them too.
export const INSTRUMENTS = {
  dob_8inch: { label: '8" Dobsonian', color: '#7aa2ff' },
  dwarf_mini: { label: 'Dwarf Mini', color: '#f0abfc' },
}

<script setup>
import { computed, onBeforeUnmount, onMounted, reactive, ref, watch, watchEffect } from 'vue'
import { gsap } from 'gsap'
import { Draggable } from 'gsap/Draggable'
import { InertiaPlugin } from 'gsap/InertiaPlugin'
import skyData from '../engine/sky.json'
import {
  altAzOf, camera, darkness, edgeMarker, fieldOfView, horizonVector, moonPath, rotate, targetHorizon, terrainSeed,
  unitVector,
} from '../engine/sky'
import { ZOOM_STEP } from '../composables/useSkyView'
import { compass, fmtTime } from '../format'
import { reduceMotion, tipIn, tipOut } from '../motion'
import SkyCanvas from './SkyCanvas.vue'

gsap.registerPlugin(Draggable, InertiaPlugin)

const props = defineProps({
  sky: { type: Object, required: true }, // useSkyView(): time, view and zoom, shared by the tile and the sky page
  location: { type: Object, required: true },
  targets: { type: Array, required: true }, // tonight-plan targets to ring, each with `instruments` (see topTargets)
  immersive: { type: Boolean, default: false }, // sky page: plain wheel zooms, one finger drags both ways
})
const emit = defineEmits(['failed'])

const DEG = 180 / Math.PI
const NAMES = skyData.names.map(([abbr, name, ra, dec]) => ({ abbr, name, v: unitVector(ra, dec) }))

const sky = props.sky // App.vue owns one for the whole visit, so this prop never changes
const view = sky.view
const stage = ref(null)
const size = reactive({ width: 1000, height: 385 }) // jsdom has no layout; the ResizeObserver takes over in browsers
// Zoom narrows the field down to 4× or 30°, whichever is wider: sky.json has no stars fainter than magnitude 5.
watchEffect(() => { sky.zoomMax = Math.min(4, fieldOfView(size.width) / 30) })
const frame = computed(() => sky.frame)
const cam = computed(() => camera({
  yaw: view.yaw, pitch: view.pitch, hfov: fieldOfView(size.width) / Math.min(view.zoom, sky.zoomMax),
  width: size.width, height: size.height,
}))
const seed = computed(() => terrainSeed(props.location))
const dark = computed(() => darkness(frame.value))

// Overlay: everything is placed in stage px by the same camera the shaders use.
const pos = (p) => ({ left: `${p.x}px`, top: `${p.y}px` })
const positioned = computed(() => props.targets.flatMap((t) => {
  const v = targetHorizon(t, frame.value)
  return v ? [{ ...t, ...altAzOf(v), v }] : []
}))
const placed = computed(() => positioned.value.filter((r) => r.alt > 0).map((r) => ({ ...r, p: cam.value.project(r.v) })))
// A ring needs its whole 24px inside the stage; nearer the edge than that, the target gets an edge marker instead.
const inside = ({ p }) => p.onScreen && p.x >= 12 && p.x <= size.width - 12 && p.y >= 12 && p.y <= size.height - 12
const rings = computed(() => placed.value.filter(inside))
// Best-scoring first; a marker that would overlap one already placed is skipped until the view turns.
// Chip width is estimated from the label (~7px a character plus padding) since layout isn't measured.
const edges = computed(() => placed.value.filter((r) => !inside(r)).sort((a, b) => b.score - a.score)
  .reduce((kept, r) => {
    const edge = edgeMarker(r.v, cam.value)
    const w = 7 * (r.name.length + 2) + 20
    const clear = kept.every((k) => Math.abs(k.edge.x - edge.x) >= (k.w + w) / 2 || Math.abs(k.edge.y - edge.y) >= 24)
    return clear ? [...kept, { ...r, edge, w }] : kept
  }, []))
const planets = computed(() => frame.value.planets.filter((pl) => pl.alt > 0)
  .map((pl) => ({ ...pl, p: cam.value.project(horizonVector(pl)) })).filter((pl) => pl.p.onScreen))
const labels = computed(() => NAMES.flatMap((n) => {
  const h = rotate(frame.value.rot, n.v)
  const p = cam.value.project(h)
  return h[2] > 0.05 && p.onScreen ? [{ ...n, p }] : []
}))
const compassMarks = computed(() => [0, 45, 90, 135, 180, 225, 270, 315].flatMap((az) => {
  const p = cam.value.project(horizonVector({ alt: 0, az }))
  return p.onScreen ? [{ az, label: compass(az), p }] : []
}))
const moonDisc = computed(() => {
  const { moon, sun } = frame.value
  if (moon.alt <= 0) return null
  const m = horizonVector(moon)
  const p = cam.value.project(m)
  if (!p.onScreen) return null
  // A small step from the Moon toward the Sun gives the lit limb's direction on screen.
  const s = horizonVector(sun)
  const toward = m.map((c, i) => c + (s[i] - c) * 0.02)
  const n = Math.hypot(...toward)
  const q = cam.value.project(toward.map((c) => c / n))
  return { p, path: moonPath(moon.illum, 9), angle: Math.atan2(q.y - p.y, q.x - p.x) * DEG }
})
const ringStyle = (r) => {
  const [a, b = a] = r.instruments.map((i) => INSTRUMENTS[i]?.color ?? '#fff')
  return { ...pos(r.p), '--ring-a': a, '--ring-b': b }
}
const ringLabel = (r) => `${r.name}, ${r.targetClass}, ${Math.round(r.alt)}° up, ${compass(r.az)}`
const ringHover = ref(null)
const selected = computed(() => rings.value.find((r) => r.id === ringHover.value))

// The time is announced once it has been still for half a second, not on every scrub step.
const status = ref('')
let statusTimer = 0
watch(() => sky.time, () => {
  clearTimeout(statusTimer)
  statusTimer = setTimeout(() => {
    status.value = `${sky.timeLabel}, ${placed.value.length} of ${positioned.value.length} targets above the horizon`
  }, 500)
}, { immediate: true })

const ZOOM_KEYS = { '+': ZOOM_STEP, '=': ZOOM_STEP, '-': 1 / ZOOM_STEP, _: 1 / ZOOM_STEP }
const KEYS = { ArrowLeft: [-10, 0], ArrowRight: [10, 0], ArrowUp: [0, 5], ArrowDown: [0, -5] }
function onKey(e) {
  if (ZOOM_KEYS[e.key]) { e.preventDefault(); return sky.zoomBy(ZOOM_KEYS[e.key]) }
  const k = KEYS[e.key]
  if (!k) return
  e.preventDefault()
  sky.touch()
  view.yaw += k[0]
  view.pitch = Math.min(85, Math.max(5, view.pitch + k[1]))
}
// On the tile a plain scroll keeps scrolling the page and shows how to zoom instead; Ctrl + scroll zooms
// (trackpad pinches arrive as Ctrl + wheel too). The sky page fills the screen, so there a plain scroll zooms.
const hint = ref('')
let hintTimer = 0
function showHint(text) {
  hint.value = text
  clearTimeout(hintTimer)
  hintTimer = setTimeout(() => { hint.value = '' }, 1500)
}
function onWheel(e) {
  if (!props.immersive && !e.ctrlKey && !e.metaKey) {
    return showHint(`${/Mac|iPhone|iPad/.test(navigator.platform) ? '⌘' : 'Ctrl'} + scroll to zoom`)
  }
  e.preventDefault()
  hint.value = ''
  sky.zoomBy(Math.exp(-e.deltaY * 0.002), false)
}

// Two fingers zoom by how far apart they move and tilt by how far they move up or down together (on the tile one
// finger only turns, so vertical swipes scroll the page); the drag pauses until fewer than two are down.
const fingers = new Map()
let pinch = null
let hinted = false
const spanOf = () => { const [a, b] = [...fingers.values()]; return Math.hypot(a.x - b.x, a.y - b.y) }
const midY = () => { const [a, b] = [...fingers.values()]; return (a.y + b.y) / 2 }
function onPointerDown(e) {
  fingers.set(e.pointerId, { x: e.clientX, y: e.clientY })
  if (e.pointerType === 'touch' && !hinted) {
    hinted = true
    showHint(props.immersive ? 'Pinch to zoom' : 'Two fingers to tilt and zoom')
  }
  if (fingers.size !== 2) return
  drag?.disable()
  pinch = { span: spanOf() || 1, zoom: view.zoom, y: midY() }
}
function onPointerMove(e) {
  if (!fingers.has(e.pointerId)) return
  fingers.set(e.pointerId, { x: e.clientX, y: e.clientY })
  if (!pinch) return
  sky.touch()
  view.zoom = sky.clampZoom(pinch.zoom * spanOf() / pinch.span)
  const y = midY()
  view.pitch = Math.min(85, Math.max(5, view.pitch + (y - pinch.y) * cam.value.degPerPx))
  pinch.y = y
}
function onPointerUp(e) {
  fingers.delete(e.pointerId)
  if (pinch && fingers.size < 2) { pinch = null; drag?.enable() }
}

const onEsc = (e) => { if (e.key === 'Escape') ringHover.value = null }

let drag = null
let observer = null
onMounted(() => {
  document.addEventListener('keydown', onEsc)
  if (typeof ResizeObserver !== 'undefined') {
    observer = new ResizeObserver(([e]) => {
      if (e.contentRect.width > 0) { size.width = e.contentRect.width; size.height = e.contentRect.height }
    })
    observer.observe(stage.value)
  }
  // Dragging moves the sky with the pointer. On the tile's touch screens only sideways, so vertical swipes scroll.
  let last = null
  const move = function () {
    const d = cam.value.degPerPx
    view.yaw -= (this.x - last.x) * d
    view.pitch = Math.min(85, Math.max(5, view.pitch + (this.y - last.y) * d))
    last = { x: this.x, y: this.y }
  }
  drag = Draggable.create(document.createElement('div'), {
    trigger: stage.value,
    type: !props.immersive && window.matchMedia?.('(pointer: coarse)').matches ? 'x' : 'x,y',
    inertia: !reduceMotion(),
    dragClickables: false,
    onPress() { sky.touch(); last = { x: this.x, y: this.y } },
    onDrag: move,
    onThrowUpdate: move,
  })[0]
})
onBeforeUnmount(() => {
  drag?.kill()
  observer?.disconnect()
  clearTimeout(statusTimer)
  clearTimeout(hintTimer)
  document.removeEventListener('keydown', onEsc)
})
</script>
```

```js
/**
 * Displayable targets of each instrument (only the first `per` of each when given), one entry per id listing every
 * instrument that has it and the best score among them.
 */
export function allTargets(instruments, per = Infinity) {
  const byId = new Map()
  for (const [instrument, list] of Object.entries(instruments ?? {})) {
    for (const t of list.filter(isDisplayable).slice(0, per)) {
      const seen = byId.get(t.id)
      if (seen) {
        seen.instruments.push(instrument)
        seen.score = Math.max(seen.score, t.score)
      } else byId.set(t.id, { ...t, instruments: [instrument] })
    }
  }
  return [...byId.values()]
}

/** The first `per` displayable targets of each instrument (the home tile's rings). */
export const topTargets = (instruments, per = 5) => allTargets(instruments, per)

/** The sky page's list: `instrument` ('all' or a key), optionally only targets above the horizon in `frame`. */
export function filterTargets(targets, { instrument = 'all', upOnly = false } = {}, frame = null) {
  return targets
    .filter((t) => instrument === 'all' || t.instruments.includes(instrument))
    .filter((t) => !upOnly || (frame && (targetHorizon(t, frame)?.[2] ?? -1) > 0))
    .sort((a, b) => b.score - a.score)
}
```

```js
/** Play: `time` moved on by `ms`, stopping at the end of `range` (then `done` is true). */
export function playStep(time, range, ms) {
  const end = range.end.getTime()
  return time + ms >= end ? { time: end, done: true } : { time: time + ms, done: false }
}

/** `time` moved by `deltaMs`, snapped to the scrubber's 5-minute grid (which starts at sunset) and kept in `range`. */
export function stepTime(time, range, deltaMs, step = 300_000) {
  const start = range.start.getTime()
  const t = start + Math.round((time + deltaMs - start) / step) * step
  return Math.min(range.end.getTime(), Math.max(start, t))
}
```

```js
const OBLIQUITY = 23.4393 * RAD
/** The ecliptic as J2000 segments `[a, b]` of unit vectors, every `step` degrees of longitude. */
export function eclipticLine(step = 2) {
  const at = (lon) => {
    const l = lon * RAD
    return [Math.cos(l), Math.sin(l) * Math.cos(OBLIQUITY), Math.sin(l) * Math.sin(OBLIQUITY)]
  }
  return Array.from({ length: 360 / step }, (_, i) => [at(i * step), at((i + 1) * step)])
}

/** Horizon-frame segments: altitude circles every 15° and azimuth lines every 30°, stopping 3° short of the zenith. */
export function gridLines() {
  const segs = []
  for (let alt = 15; alt < 90; alt += 15) {
    for (let az = 0; az < 360; az += 3) segs.push([horizonVector({ alt, az }), horizonVector({ alt, az: az + 3 })])
  }
  for (let az = 0; az < 360; az += 30) {
    for (let alt = 0; alt < 87; alt += 3) segs.push([horizonVector({ alt, az }), horizonVector({ alt: alt + 3, az })])
  }
  return segs
}

/** The meridian, from the north horizon over the zenith to the south horizon, as horizon-frame segments. */
export function meridianLine(step = 2) {
  const at = (a) => (a <= 90 ? horizonVector({ alt: a, az: 0 }) : horizonVector({ alt: 180 - a, az: 180 }))
  return Array.from({ length: 180 / step }, (_, i) => [at(i * step), at((i + 1) * step)])
}
```

```js
const norm = (s) => s.toLowerCase().replace(/\s+/g, '')
const KIND_ORDER = ['target', 'planet', 'moon', 'deep-sky', 'variable', 'constellation', 'star']

/** Everything search can find. Tonight's targets come first and win over their catalogue or planet copies. */
export function searchIndex(instruments) {
  const entries = allTargets(instruments).map((t) => ({ name: t.name, id: t.id, kind: 'target', aliases: [t.id], target: t }))
  const taken = new Set(entries.flatMap((e) => [norm(e.id), norm(e.name)]))
  const add = (e) => {
    if ([e.id, e.name].some((k) => taken.has(norm(k)))) return
    taken.add(norm(e.id))
    entries.push(e)
  }
  PLANETS.forEach((p) => add({ name: cap(p), id: cap(p), kind: 'planet', aliases: [] }))
  add({ name: 'Moon', id: 'Moon', kind: 'moon', aliases: [] })
  DEEP_SKY.forEach((o) => add({ name: o.name, id: o.id, kind: 'deep-sky', aliases: [o.id], v: o.v }))
  catalogs.watchlist.forEach((o) =>
    add({ name: o.designation, id: o.designation, kind: 'variable', aliases: [], v: unitVector(o.raHours, o.decDegrees) }))
  skyData.names.forEach(([abbr, name, ra, dec]) =>
    add({ name, id: abbr, kind: 'constellation', aliases: [abbr], v: unitVector(ra, dec) }))
  skyData.starNames.forEach(([name, ra, dec]) => add({ name, id: name, kind: 'star', aliases: [], v: unitVector(ra, dec) }))
  return entries
}

/** Up to `limit` entries for `query`: exact name or id first, then word prefixes, then substrings; ties by kind, name. */
export function searchSky(index, query, limit = 8) {
  const q = norm(query ?? '')
  if (!q) return []
  const rank = (e) => {
    const keys = [e.name, e.id, ...e.aliases].filter(Boolean)
    if (keys.some((k) => norm(k) === q)) return 0
    if (keys.some((k) => norm(k).startsWith(q) || k.toLowerCase().split(/[^a-z0-9]+/).some((w) => w && w.startsWith(q)))) return 1
    if (keys.some((k) => norm(k).includes(q))) return 2
    return -1
  }
  return index.map((e) => ({ e, r: rank(e) })).filter(({ r }) => r >= 0)
    .sort((a, b) => a.r - b.r || KIND_ORDER.indexOf(a.e.kind) - KIND_ORDER.indexOf(b.e.kind) || a.e.name.localeCompare(b.e.name))
    .slice(0, limit)
    .map(({ e }) => e)
}

/** Horizon vector of a search entry in `frame`. */
export function entryHorizon(entry, frame) {
  if (entry.target) return targetHorizon(entry.target, frame)
  if (entry.kind === 'planet') return horizonVector(frame.planets.find((p) => p.id === entry.id))
  if (entry.kind === 'moon') return horizonVector(frame.moon)
  return rotate(frame.rot, entry.v)
}
```

```vue
<script setup>
import { computed, onBeforeUnmount, ref, watch } from 'vue'
import { ZOOM_STEP } from '../composables/useSkyView'
import {
  allTargets, altAzOf, entryHorizon, filterTargets, playStep, searchIndex, stepTime, targetHorizon,
} from '../engine/sky'
import { reduceMotion } from '../motion'
import SkyLayersMenu, { loadLayers, saveLayers } from './SkyLayersMenu.vue'
import SkyScrubber from './SkyScrubber.vue'
import SkySearch from './SkySearch.vue'
import SkyStage from './SkyStage.vue'
import SkyTargetPanel from './SkyTargetPanel.vue'

const props = defineProps({
  sky: { type: Object, required: true }, // useSkyView(), shared with the home tile
  location: { type: Object, required: true },
  tonight: { type: Object, default: null },
  bestHour: { type: String, default: null }, // ISO start of the best dark hour, once the forecast is in
  loading: { type: Boolean, default: false }, // tonight's plan is loading
  error: { type: String, default: null }, // tonight's plan failed
})

const HOUR = 3_600_000
const failed = ref(false) // no WebGL: the list and search still work
const instrument = ref('all')
const upOnly = ref(false)
const selectedId = ref(null)
const hoverId = ref(null)
const panelOpen = ref(!window.matchMedia?.('(max-width: 700px)').matches) // phones open on the sky, not the list
const layers = ref(loadLayers())
watch(layers, saveLayers)

const all = computed(() => allTargets(props.tonight?.instruments))
const shown = computed(() =>
  filterTargets(all.value, { instrument: instrument.value, upOnly: upOnly.value }, props.sky.frame))
const rows = computed(() => shown.value.map((t) => {
  const v = targetHorizon(t, props.sky.frame)
  return { ...t, pos: v && altAzOf(v) }
}))
// The ten best of what the list shows ring at full strength; the rest are dimmed until hovered or picked.
const emphasis = computed(() => new Set(shown.value.slice(0, 10).map((t) => t.id)))
props.sky.follow(() => props.location, { targets: () => shown.value, bestHour: () => props.bestHour })

function pick(row) {
  selectedId.value = row.id
  if (row.pos && !failed.value) props.sky.turnTo(row.pos)
}

// Search: turn to the pick and mark it; below the horizon, say so instead (the toast is also the live region).
const index = computed(() => searchIndex(props.tonight?.instruments))
const highlight = ref(null)
const notice = ref('')
let noticeTimer = 0
function say(text) {
  notice.value = text
  clearTimeout(noticeTimer)
  noticeTimer = setTimeout(() => { notice.value = '' }, 4000)
}
function onFind(entry) {
  highlight.value = entry
  if (entry.target) selectedId.value = entry.id
  const at = altAzOf(entryHorizon(entry, props.sky.frame))
  if (!failed.value) props.sky.turnTo(at)
  if (at.alt <= 0) say(`${entry.name} is below the horizon at ${props.sky.timeLabel}`)
}
function clearFind() {
  highlight.value = null
  notice.value = ''
}

// Play runs the night at an hour per second (with reduced motion, a jump of an hour each second) and stops at sunrise.
const playing = ref(false)
let raf = 0
let timer = 0
let last = 0
function advance(ms) {
  const next = playStep(props.sky.time, props.sky.range, ms)
  props.sky.time = next.time
  if (next.done) pause()
}
function tick(t) {
  advance((t - last) * HOUR / 1000)
  last = t
  if (playing.value) raf = requestAnimationFrame(tick)
}
function play() {
  props.sky.touch()
  if (props.sky.time >= props.sky.range.end.getTime()) props.sky.time = props.sky.range.start.getTime()
  playing.value = true
  if (reduceMotion()) timer = setInterval(() => advance(HOUR), 1000)
  else {
    last = performance.now()
    raf = requestAnimationFrame(tick)
  }
}
function pause() {
  playing.value = false
  cancelAnimationFrame(raf)
  clearInterval(timer)
}
const inNight = (t) => t >= props.sky.range.start.getTime() && t <= props.sky.range.end.getTime()
const nowInNight = computed(() => inNight(props.sky.now.getTime()))
const bestInNight = computed(() => props.bestHour != null && inNight(Date.parse(props.bestHour)))
function jump(t) {
  pause()
  props.sky.setTime(t)
}
const step = (dir) => jump(stepTime(props.sky.time, props.sky.range, dir * HOUR))
const jumpNow = () => jump(Math.min(props.sky.range.end.getTime(), Math.max(props.sky.range.start.getTime(), Date.now())))

watch(() => props.location, () => {
  pause()
  clearFind()
  selectedId.value = null
})
onBeforeUnmount(() => {
  pause()
  clearTimeout(noticeTimer)
})
</script>

<template>
  <section class="panel sky-page" :aria-label="`Sky over ${location.name}`">
    <div class="sky-toolbar">
      <SkySearch :index="index" :frame="sky.frame" @pick="onFind" @clear="clearFind" />
      <SkyLayersMenu v-model="layers" />
      <button class="show-more sky-targets-toggle" :aria-expanded="panelOpen" @click="panelOpen = !panelOpen">
        Targets ({{ rows.length }})
      </button>
    </div>
    <div class="sky-body" :class="{ 'panel-open': panelOpen }">
      <div class="sky-main">
        <SkyStage v-if="!failed" v-model:selected-id="selectedId" :sky="sky" :location="location" :targets="shown"
                  :hover-id="hoverId" :emphasis="emphasis" :layers="layers" :highlight="highlight" immersive
                  @failed="failed = true" />
        <p v-else class="sky-nogl muted">Your browser can't draw the sky (WebGL is unavailable).</p>
        <p class="sky-notice" role="status" aria-live="polite">{{ notice }}</p>
      </div>
      <SkyTargetPanel v-if="panelOpen" v-model:instrument="instrument" v-model:up-only="upOnly" :rows="rows"
                      :selected-id="selectedId" :loading="loading && !tonight" :error="error" @pick="pick"
                      @hover="hoverId = $event" @close="panelOpen = false" />
    </div>
    <div class="sky-scrub sky-timebar">
      <button class="show-more sky-ctl" :aria-label="playing ? 'Pause' : 'Play the night'"
              @click="playing ? pause() : play()">{{ playing ? '⏸' : '▶' }}</button>
      <button class="show-more sky-ctl" aria-label="Back one hour" @click="step(-1)">−1h</button>
      <SkyScrubber :sky="sky" :best-hour="bestHour" @scrub="pause" />
      <button class="show-more sky-ctl" aria-label="Forward one hour" @click="step(1)">+1h</button>
      <button class="show-more sky-ctl" :disabled="!nowInNight" @click="jumpNow">Now</button>
      <button v-if="bestInNight" class="show-more sky-ctl" @click="jump(Date.parse(bestHour))">Best</button>
      <div class="btn-group zoom" role="group" aria-label="zoom">
        <button aria-label="zoom out" :disabled="sky.view.zoom <= 1" @click="sky.zoomBy(1 / ZOOM_STEP)">−</button>
        <button aria-label="zoom in" :disabled="sky.view.zoom >= sky.zoomMax" @click="sky.zoomBy(ZOOM_STEP)">+</button>
      </div>
      <span class="sky-time">{{ sky.timeLabel }}</span>
    </div>
  </section>
</template>
```
