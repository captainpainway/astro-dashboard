# Lunar Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a shader-rendered Moon for *now* in `LunarView`, with a clickable dot per feature that opens a name tooltip.

**Architecture:** `src/engine/moonview.js` holds the pure math (sub-Earth point from libration, sub-solar point, north-up view basis, lat/lon to screen). `MoonMap.vue` draws a lit sphere with one raw-WebGL fragment shader sampling a bundled equirectangular texture, and overlays HTML dot buttons positioned with the same basis, so dots and shading cannot disagree. `LunarView` mounts it above the table with its tier-filtered features.

**Tech Stack:** Vue 3, `astronomy-engine` (`Libration`, already a dependency), raw WebGL1, vitest + jsdom, Playwright/chrome-devtools MCP for the visual check.

**Spec:** `docs/superpowers/specs/2026-10-03-lunar-map-design.md`

**Working rules:** implement directly on branch `lunar-map` (no new branch, no worktree). Never leave build output in the repo: build only with `--outDir` in the scratchpad. No new dependencies.

## Global Constraints

- North-up orientation only; "now" is read once on mount; no scrubber, zoom, pan, or row linking.
- No three.js; raw WebGL, one quad, one fragment shader.
- No relief/bump lighting (no heightmap).
- Texture: NASA SVS CGI Moon Kit color map (public domain), `src/assets/moon-2k.jpg`, 2048×1024 JPEG, about 1 MB.
- Frame: selenographic, east-positive longitude, same as `subsolarPoint` and `lunar.json`.
- No WebGL: the map (canvas and dots) is not rendered; the table works as before.
- Features without `lat`/`lon` (phase rows) get no dots. Use `f.lat != null`, never truthiness (lat 0 is valid).
- Dots only on the Earth-facing hemisphere.
- Tests: run only `npx vitest run <files>`; extend `tests/LunarView.test.js` rather than adding a component test file.

## Review Focus

- Far-side feature (e.g. lon 180) must get no dot, not a mirrored one. Pinned in Task 2.
- Feature on the equator or prime meridian (`lat: 0`) must still get a dot. Pinned in Task 2.
- Switching tier while a tooltip is open for a feature that then disappears must close the tooltip without error. Pinned in Task 2.
- No WebGL (jsdom default, or `getContext` returns null) must hide the map but leave the table intact. Pinned in Task 2.
- Texture fails to load: hide the whole map rather than show floating dots on a blank disc. Pinned in Task 2.

Create `src/engine/moonview.js`:

```js
import { Libration } from 'astronomy-engine'
import { subsolarPoint } from './lunar'

const RAD = Math.PI / 180

// Body frame: x toward lon 0 / lat 0, y toward 90°E, z toward the north pole.
export const sunVector = ({ lat, lon }) =>
  [Math.cos(lat * RAD) * Math.cos(lon * RAD), Math.cos(lat * RAD) * Math.sin(lon * RAD), Math.sin(lat * RAD)]

const dot = (a, b) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2]
const cross = (a, b) => [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]]

/** Sub-solar and sub-Earth points (selenographic degrees, east-positive) at `date`. */
export function moonView(date) {
  const { elat, elon } = Libration(date)
  return { sub: subsolarPoint(date), earth: { lat: elat, lon: elon } }
}

/** North-up screen basis seen from `earth`: +x right (east), +y up (north), `earth` toward the viewer. */
export function viewBasis(earth) {
  const e = sunVector(earth)
  const k = e[2]
  const n = Math.sqrt(1 - k * k) // |z - k·e|
  const up = [(0 - k * e[0]) / n, (0 - k * e[1]) / n, (1 - k * e[2]) / n]
  return { right: cross(up, e), up, earth: e }
}

/** Unit-disc position of a selenographic point; `visible` when it faces Earth. */
export function project(pt, { right, up, earth }) {
  const p = sunVector(pt)
  return { x: dot(p, right), y: dot(p, up), visible: dot(p, earth) > 0 }
}
```

```vue
<script setup>
import { computed, onBeforeUnmount, onMounted, ref } from 'vue'
import { moonView, project, sunVector, viewBasis } from '../engine/moonview'
// NASA SVS CGI Moon Kit (public domain): LROC color map, 2048x1024 equirectangular.
import textureUrl from '../assets/moon-2k.jpg'

const props = defineProps({ features: { type: Array, required: true } })

const SIZE = 768
const view = moonView(new Date()) // read once: the map shows the Moon as it is now
const basis = viewBasis(view.earth)
const failed = ref(typeof WebGLRenderingContext === 'undefined')
const canvas = ref(null)
const selectedId = ref(null)

const dots = computed(() => props.features
  .filter((f) => f.lat != null)
  .map((f) => ({ id: f.id, name: f.name, ...project(f, basis) }))
  .filter((d) => d.visible))
const selected = computed(() => dots.value.find((d) => d.id === selectedId.value))
const pos = (d) => ({ left: `${50 + d.x * 50}%`, top: `${50 - d.y * 50}%` })

const VERT = `attribute vec2 aPos; varying vec2 vPos;
void main() { vPos = aPos; gl_Position = vec4(aPos, 0.0, 1.0); }`
const FRAG = `precision highp float;
varying vec2 vPos;
uniform sampler2D uTex;
uniform vec3 uRight, uUp, uEarth, uSun;
const float PI = 3.14159265;
void main() {
  float r2 = dot(vPos, vPos);
  if (r2 > 1.0) discard;
  vec3 p = vPos.x * uRight + vPos.y * uUp + sqrt(1.0 - r2) * uEarth;
  vec2 uv = vec2(atan(p.y, p.x) / (2.0 * PI) + 0.5, 0.5 - asin(clamp(p.z, -1.0, 1.0)) / PI);
  float lit = mix(0.04, 1.0, smoothstep(-0.02, 0.12, dot(p, uSun)));
  float limb = 0.55 + 0.45 * sqrt(1.0 - r2);
  gl_FragColor = vec4(texture2D(uTex, uv).rgb * lit * limb, 1.0);
}`

function draw(gl, img) {
  const compile = (type, src) => {
    const s = gl.createShader(type)
    gl.shaderSource(s, src)
    gl.compileShader(s)
    if (!gl.getShaderParameter(s, gl.COMPILE_STATUS)) throw new Error(gl.getShaderInfoLog(s))
    return s
  }
  const prog = gl.createProgram()
  gl.attachShader(prog, compile(gl.VERTEX_SHADER, VERT))
  gl.attachShader(prog, compile(gl.FRAGMENT_SHADER, FRAG))
  gl.linkProgram(prog)
  gl.useProgram(prog)
  gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer())
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1, -1, 1, -1, -1, 1, 1, 1]), gl.STATIC_DRAW)
  const a = gl.getAttribLocation(prog, 'aPos')
  gl.enableVertexAttribArray(a)
  gl.vertexAttribPointer(a, 2, gl.FLOAT, false, 0, 0)
  gl.bindTexture(gl.TEXTURE_2D, gl.createTexture())
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGB, gl.RGB, gl.UNSIGNED_BYTE, img)
  gl.generateMipmap(gl.TEXTURE_2D) // texture is a power of two, as WebGL1 requires
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR_MIPMAP_LINEAR)
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR)
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE)
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE)
  const set3 = (name, v) => gl.uniform3fv(gl.getUniformLocation(prog, name), v)
  set3('uRight', basis.right)
  set3('uUp', basis.up)
  set3('uEarth', basis.earth)
  set3('uSun', sunVector(view.sub))
  gl.viewport(0, 0, SIZE, SIZE)
  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4)
}

const close = () => { selectedId.value = null }
const onKey = (e) => { if (e.key === 'Escape') close() }

onMounted(() => {
  document.addEventListener('click', close)
  document.addEventListener('keydown', onKey)
  if (failed.value) return
  const gl = canvas.value.getContext('webgl')
  if (!gl) { failed.value = true; return }
  const img = new Image()
  img.onload = () => { try { draw(gl, img) } catch { failed.value = true } }
  img.onerror = () => { failed.value = true }
  img.src = textureUrl
})
onBeforeUnmount(() => {
  document.removeEventListener('click', close)
  document.removeEventListener('keydown', onKey)
})
</script>

<template>
  <div v-if="!failed" class="moon-map">
    <canvas ref="canvas" :width="SIZE" :height="SIZE" />
    <button v-for="d in dots" :key="d.id" class="moon-dot" :class="{ active: d.id === selectedId }"
            :style="pos(d)" :aria-label="d.name" @click.stop="selectedId = d.id" />
    <span v-if="selected" class="moon-tip" role="tooltip" :style="pos(selected)">{{ selected.name }}</span>
  </div>
</template>
```
